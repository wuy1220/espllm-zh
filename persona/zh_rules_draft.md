# 中文接话规则层草案（L0）

## 为什么要有这一层

`probe_zh_kl.py` 三个数说明一切（同一个 `User: X\nBot: ` 模板、同一套归一化）：

| 输入 | pairwise 归一化 KL |
|---|---|
| 语料原句（背过） | **1.50** |
| 我手写的同类短问句（没背过） | 0.15 |
| 罐头外（情绪/互动/怪问题） | 0.07 |

也就是说：**它不是"理解得浅"，是逐字查表**。换一个说法，查表就落空，落到 337 条规范回复的边缘分布上。
在这个尺寸上继续训练来"教它理解"是死路，正确做法是把"判断该说什么"搬到规则层，
模型只负责"怎么说"。规则层 0 ms、零容量成本、可调试——这是这块板子上唯一能保证鲁棒的地方。

## 命中规则

1. 按帧顺序匹配（后面的帧优先级更高，见帧前的数字），**命中即返回**，不再问模型。
2. 匹配用子串（中文按 UTF-8 字节 `strstr` 就是子串匹配），一个帧内多关键词命中取分数最高。
3. 同一帧内**随机挑一条**回复（`random()` 即可）。这本身就是多样性来源，且永不重复同一句。
4. 单字触发（`⑨` `笨` `九`）只在**整句长度 ≤3** 时生效，避免"笨蛋节"误命中。
5. 回复全部 `PROGMEM`，一条 20 汉字 ≈ 60 B；本表 100 条 ≈ 6 KB，Flash 余量 ~64 KB 够用。

## 还需要配套改的两处

1. **canon 塌缩 bug**：`自我介绍` 这一组 150 条 prompt 只对应 3 个目标，其中 **93 条（62%）**
   答的都是 `咱住雾之湖边的冰屋，凉快得很。`——`你几岁` `你叫什么名字` `你是什么妖精`
   `幻想乡是什么地方` 全被映射到"住哪"。原因在 `canon_zh_corpus.py`：`merge_below` 把
   11 个子话题并回父话题 `自我介绍`，再在这个混合池里取 medoid，medoid 只能答其中一支。
   截图第一句 `你谁啊 -> 咱住雾之湖边的冰屋` 就是它。
   修法：合并只允许发生在**字面相似**的组之间（2-gram Jaccard ≥ 0.3），或者干脆不合并，
   让小组各自成目标（会多出约 29 个目标，容量扛得住）。
2. **别去打「`Bot:` 后面那个空格」的主意**：训练是 `prompt + " " + ans`，板端 prefill 只到
   `Bot:`，每回合第一个 token 必定是空格。看着像白花一步，但板上没有 KV cache、每步都重算
   整窗，把空格塞进 prompt 会让后面每一步都多算一格，两者基本等价。不是优化项。

# 落地记录（2026-10-21，已烧录验证）

## 实际形态

`intent_rules.py` 里 `ZH_RULES`：**19 帧 / 157 关键词 / 84 条回复**，
`gen_rules_cpp.py` 生成到 `intent_rules_gen.h`，固件里排在英文规则之后（中文输入不会命中英文词）。
占用：Flash 94.7%（988,687 / 1,044,464）、RAM 92.1%、空闲堆 4,968 B。
命中 0 ms；未命中走模型 2.1~2.7 s。

`coverage_zh_rules.py`：47 条用例，**47/47** 落到预期帧，其中 8 条刻意留给模型。

## 落地时改掉的三个设计错误

1. **规则会抢模型的活。** 第一版把"大妖精/灵梦/魔理沙"写进关键词，
   `大妖精比你稳重多了` 被规则答成"朋友？当然有，虽然她们老说咱笨"——
   而模型本来答得对。**规则只该拦模型接不住的帧（外号/互动/情绪/怪问题），
   不该拦它已经会的话题。** 话题名词从关键词表里全部撤掉，只留"关系类问句"。
2. **一帧不能混多个对象。** `你认识大妖精吗` 抽到"魔理沙那家伙，早晚输给咱"。
   大妖精拆成单独一帧（`zh_friend_dyj`）；灵梦/魔理沙仍交给模型，因为它答得更好
   （`那次是咱让着她！下次一定赢回来！`）。
3. **长句要兜底。** 真实输入最多的不是问句，是长陈述（"今天被老板骂了，路上还下雨"）。
   `zh_listen` 没有关键词、只按 ≥30 B 触发，给"倾听+站队"的通用句，
   比模型随机挑一句规范回复好得多。短句仍交给模型。

## 禁首字（anti-repeat）

`BAN_SLOTS=4`，记最近 4 条回复的首字（每条 ≤4 B）。因为词表是字符级，
"禁首字"精确到 token：采样第一步把命中候选的概率压到 0，规则层抽签时同样跳过。
实测板上 13 句连发，**相邻同首字 0/12**（改之前 3/12）。运行时可 `:norep 0|1` 关掉对比。

只禁首字、不禁前两字：字符级词表下一步只出一个字，第二字要到下一步才知道，
要禁前两字就得回退已前向的 token，而这块板子没有 KV 回滚。

## canon 两处修复

| 问题 | 修法 | 效果 |
|---|---|---|
| 小组按父话题名硬并，跨子意图取 medoid | 改成按 prompt 2-gram Jaccard ≥0.30 并入最近的大组，否则自成一组 | `自我介绍` 从 3 个目标（93/150 答"冰屋"）拆成 9 个 |
| 同一 prompt 被写进多个话题，压成规范回复后自相矛盾 | prompt 级按众数去重 | `今天好热` 从 10 种答案收敛到 1 种；8,203 → 7,062 行，306 句冲突清零 |

`model_zh_canon4.pt.best`：同一批 24 条语料原句上 **贪心完全命中 10/24（42%）、
char F1 0.593、pairwise KL 1.06**——是四版里最好的（canon2 8/24、canon3 5/24）。

## 还没做

- 心情状态机、主动开口、蜂鸣器。
